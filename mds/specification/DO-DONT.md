# Launch-Readiness Lab — MDS Do / Don't

Status: Approved  
Version: MDS v1.0

| Do | Don't |
|---|---|
| Make the evidence panel, finding, and limitation visually primary. | Let decorative marketing chrome compete with proof. |
| Pair technical evidence with a plain-language consequence. | Replace evidence with vague confidence language. |
| Use exact labels such as **Remediated — documented test blocked**. | Say secure, certified, compliant, guaranteed, or generic passed. |
| Show vulnerable, remediated, untested, unavailable, running, and not-applicable states distinctly. | Use one generic success/failure treatment or imply that missing evidence passed. |
| Combine icon/shape, text label, explanation, and semantic color. | Depend on red/green alone. |
| Keep limitations adjacent to the claim they qualify. | Hide limitations in low-contrast footer copy. |
| Use light buyer surfaces, deep-ink framing, and dark technical evidence panels. | Turn the whole product into a dark hacker dashboard. |
| Use the approved boundary/check-path mark and Lucide-style outline icons. | Use shields, locks, bugs, keyholes, neon circuitry, or theatrical exploit imagery. |
| Use approved tokens and restrained borders/shadows. | Hardcode arbitrary colors, radii, spacing, or glow effects. |
| Preserve report and authorized-review routes at every viewport. | Hide material actions or evidence on mobile. |
| Stack vulnerable proof before remediation on mobile. | Shrink paired desktop panels until neither is readable. |
| Keep row identity and labels visible when a matrix scrolls. | Present unlabeled colored dots or lose row context. |
| Request high-level inquiry context only. | Request credentials, secrets, production data, or uploads in R1. |
| Acknowledge an inquiry only after confirmed submission. | Imply an engagement, response time, price, or outcome. |
| Provide retry, return, and alternate routes for unavailable states. | Convert failure or unavailability into silent success. |
| Use **REUSE → COMPOSE → EXTEND → CREATE**. | Duplicate components or invent a visual convention to finish a screen. |
